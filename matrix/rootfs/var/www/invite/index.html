Invite people

Create a sign-up link for someone, or show them how to connect their app.

These links only work on your home network

The server address is , which people outside your home can't reach. To invite friends, make the server reachable at a public https:// address (see the add-on's Documentation tab) and set it as Server address in the add-on configuration.

1. Create an invite code

In Element, open the Admin Room and send one of these:

  • !admin token issue --once — works for one person
  • !admin token issue --max-age 7d — works for anyone for 7 days
  • !admin token issue --max-uses 5 — works for 5 people

The server replies with a code. To see or cancel codes later, send !admin token list or !admin token revoke <code>.

Have them scan this or open the link to choose a username and password. Then they sign in with the Element app.
