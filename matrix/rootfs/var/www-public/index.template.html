Our private chat

This is a small, private chat server run by a family for family and friends. If your child has been invited, this page explains what it is and how it's kept safe.

What is it?

A messaging service, like WhatsApp or iMessage, that runs on a computer in our home instead of on a big company's servers. It uses Matrix, an open, widely used chat standard, so people chat using free, well-known apps such as Element or FluffyChat.

Who can join?

  • Invitation only. There is no public sign-up. Every account needs a personal invite link from the person who runs the server.
  • {{FEDERATION}}
  • Accounts can be removed at any time if someone shouldn't be here.

Privacy

  • No ads, no tracking, no data sold. Nothing is shared with advertisers or third parties.
  • Private conversations are end-to-end encrypted: only the people in the chat can read them. Not even the person running the server can read those messages.
  • Messages and files are stored on the server in our home and included in its backups.

Safety

  • People can only be reached by others on this server, and anyone can leave or block a chat.
  • If something concerning happens, contact us (below). We can remove an account or a room.
  • We encourage you to talk with your child about who they chat with, as with any app.

How to join

  1. Get an invite link or QR code from us, open it, and choose a username and password.
  2. Install Element or FluffyChat from the App Store or Google Play.
  3. On the sign-in screen, change the server to {{SERVER}} and sign in.
