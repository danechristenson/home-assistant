# Home Assistant Add-on: VoceChat

Self-hosted, lightweight chat server with a web UI.

![Supports amd64 Architecture][amd64-shield]
![Supports aarch64 Architecture][aarch64-shield]

[VoceChat](https://voce.chat) is a small, self-hosted chat server with group
channels, direct messages, file sharing and a bot/webhook API. This add-on runs
the official VoceChat server on your Home Assistant host and keeps all of its
data in the add-on's persistent storage, so it is included in Home Assistant
backups.

See the **Documentation** tab for installation and configuration details.
