# Home Assistant Add-on: VoceChat

Private group chat for your family or team, hosted on Home Assistant.

![Supports amd64 Architecture][amd64-shield]
![Supports aarch64 Architecture][aarch64-shield]

[VoceChat](https://voce.chat) is a simple chat app, similar to Slack or
Discord, that runs on your own Home Assistant machine instead of someone
else's servers. Your messages and files stay at home.

- Group channels, direct messages, file and photo sharing
- Use it in any web browser, or install it to your phone's home screen
- Bots and webhooks, so Home Assistant automations can post messages
- Included in your Home Assistant backups

Note: the free version of VoceChat allows up to 20 users.

See the **Documentation** tab for installation and configuration details.
